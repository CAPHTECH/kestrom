# kestrom

The editing tools of [Kestrom](https://github.com/CAPHTECH/kestrom): edits of a language model whose range or changed tensors
`kestrom-verify` can check (output-layer rows, decode-time edits, edits inside decoder layers), and tools to find where to edit. Free under PolyForm Small Business 1.0.0
or PolyForm Noncommercial 1.0.0; other uses need a commercial license (COMMERCIAL.md).

`kestrom` with no arguments lists the commands.
