# kestrom-verify

The checker of [Kestrom](https://github.com/CAPHTECH/kestrom): compares an edited language model with its original,
byte for byte and output for output, and writes a report that rebuilds to the same bytes. Apache-2.0.

`kestrom-verify` with no arguments lists the commands. Every check and what it does not guarantee: `docs/guarantees.md` in the
repository.
