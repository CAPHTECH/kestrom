# Contributing

Issues are welcome: bug reports, checks that pass when they should not (or fail when they should not), questions, and ideas for
edits.

Pull requests are not accepted for now. `kestrom` (folder `edit/`) is offered under a commercial license as well as the PolyForm
licenses, and code written by others could not be offered that way without a contributor license agreement, which we do not have.
If you have found a fix, describe the problem in an issue, and please do not paste code you want included; we will write the fix
ourselves.
